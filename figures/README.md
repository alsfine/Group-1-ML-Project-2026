# Figures folder

This repository keeps all report figures under `figures/` in organised subfolders:

- `figures/eda/` — Stage 2 EDA figures (Fig 1–8).
- `figures/diagram/` — Stage 7 methodology block diagram (Fig 0).
- `figures/performance/` — Stage 7 performance figures + ROC overlays (Fig 9–16).

Run `project.ipynb` (Stages 1→7) to (re)generate these outputs. Stage 7 also writes a simple manifest to `figures/REPORT_FIGURES.md`.
